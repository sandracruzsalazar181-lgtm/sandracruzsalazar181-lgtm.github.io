¿Qué es un Modelo?

Un modelo es una representación matemática o visual de un fenómeno real. Nos ayuda a entender cómo funciona algo en la vida real usando números y ecuaciones.

Modelo SIR

El modelo SIR divide a la población en:

S = Susceptibles (pueden enfermarse)
I = Infectados
R = Recuperados

Este modelo usa ecuaciones diferenciales para predecir cómo se propaga una enfermedad.

Ecuaciones Cuadráticas

Una ecuación cuadrática tiene la forma:

ax² + bx + c = 0

Se pueden resolver con la fórmula general:

x = (-b ± √(b² - 4ac)) / 2a

En modelos epidemiológicos pueden usarse para analizar comportamientos y puntos de equilibrio.
